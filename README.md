## Guía de Instalación y Uso

### Requisitos para Desarrollo

Para desarrollar y probar la aplicación en tu computadora:

1. **Instalar Python**:

1. Python 3.7 o superior



2. **Instalar dependencias**:

```plaintext
pip install kivy opencv-python numpy pytesseract pywhatkit pillow
```


3. **Instalar Tesseract OCR**:

1. **Windows**: Descarga desde [github.com/UB-Mannheim/tesseract/wiki](https://github.com/UB-Mannheim/tesseract/wiki)
2. **Linux**: `sudo apt-get install tesseract-ocr`
3. **macOS**: `brew install tesseract`



4. **Ejecutar la aplicación**:

```plaintext
python parking_system_mobile.py
```
